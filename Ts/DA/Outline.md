When we study a programming language, conceptually, we have to know these:
- Variable declarations
- Conditional checking
- Looping

Then, as the next step, we have to know things like:
- Data structure (Class, Enum, Struct, etc.)
- Memory allocation
- Recursive function

The higher we go, the deeper and detailed knowledge such as 'pass by value', 'pass by reference', 'template', 'lambda', etc.

But this programming language becomes a part of application when we learn the things like
- Software design pattern
- Software architecture
