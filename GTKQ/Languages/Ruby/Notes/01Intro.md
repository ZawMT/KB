# Intro - Getting Started with Ruby

To learn Ruby, here's what you'd typically need:

1. **A working Ruby install** - check with `ruby -v` in your terminal. Ruby often comes preinstalled on macOS, but it's usually an old version; most learners use a version manager (rbenv or rvm) to install a current one.
2. **A REPL to experiment interactively** - `irb` (Interactive Ruby), similar to Python's REPL. Great for trying one-liners without creating files.
3. **A way to run scripts** - write a `.rb` file and run it with `ruby filename.rb`.
4. **A learning path/order**, roughly:
   - syntax basics (variables, types, string/number operations)
   - control flow (if/unless, loops)
   - methods (defining, arguments, return values)
   - collections (arrays, hashes) and iteration (`each`, blocks)
   - symbols vs strings (a Ruby-specific concept)
   - object orientation (classes, modules, mixins) - Ruby is "everything is an object"
   - blocks/procs/lambdas (distinctive Ruby feature)
   - gems and Bundler (package management) - later, once you're past basics
