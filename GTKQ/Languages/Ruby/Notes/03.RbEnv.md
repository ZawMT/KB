# RbEnv - Installing a Current Ruby Version

macOS ships with an old system Ruby (e.g. `2.6.10`), so the recommended approach is to manage Ruby versions with `rbenv` instead of using the system one.

**1. Check the current version:**
```
ruby -v
```

**2. Install rbenv and ruby-build via Homebrew:**
```
brew install rbenv ruby-build
```

**3. Initialize rbenv for your shell:**
```
rbenv init
```
This writes configuration into `~/.zprofile` so rbenv is set up in future shell sessions. It does **not** apply to the currently open terminal.

**4. Install a Ruby version and set it as global default:**
```
rbenv install 3.3.0
rbenv global 3.3.0
```

**5. Apply the change to the current session (without restarting the terminal):**
```
eval "$(rbenv init -)"
```

**6. Verify:**
```
ruby -v
which ruby
```
`which ruby` should point to `~/.rbenv/shims/ruby`. If it still shows an old/system path, something earlier in `PATH` (e.g. a conda `base` environment) may be taking priority.

**7. Confirm it persists** by opening a brand new terminal tab/window and running `ruby -v` again - it should show the new version without needing to re-run `eval`.

**Notes:**
- Installing rbenv/Ruby versions is a global, machine-wide setup - not tied to any project directory.
- rbenv supports per-directory Ruby versions via a `.ruby-version` file, useful later if different projects need different versions.
