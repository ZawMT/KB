# Languages — Key Points

| Key Point | Note |
|-----------|------|
| toolchain | A general software-engineering term — the set of tools used in sequence to turn source code into a running program. It will include compiler, linker, standard library, and, if needed, build tool. |
| duck typing | An object's suitability for use is determined by whether it has the methods/behavior called on it, not by its declared type or class (e.g. Ruby). Checked at runtime, not compile time — contrast with statically-typed interfaces like Rust traits. |
