## AI
### Key points

#### [Back to AI contents](_Contents.md)

| Point | Note |
|---|---|
| **Sampling temperature** | **What it controls:** how random the model's word choices are.<br><br>**Background:** an LLM writes text one **token** at a time (a token is a word or part of a word). At each step it gives every possible next token a **probability**, then picks one. Picking at random according to those probabilities is called **sampling**.<br><br>**What temperature does:** it reshapes the probabilities before the pick. Example, next token after *"The cat sat on the"*:<br>• Original (T = 1): mat 60%, sofa 25%, roof 10%, moon 5%<br>• Low (T = 0.5): mat 83%, sofa 14%, roof 2%, moon 1% → likely words get even more likely<br>• High (T = 2): mat 43%, sofa 28%, roof 17%, moon 12% → unlikely words get a real chance<br><br>**Values (OpenAI):** 0 to 2, default 1.<br>• **0**: (almost) always the most likely token → focused and repeatable, but not *guaranteed* identical every time<br>• **0–0.3**: extraction, classification, code, factual answers<br>• **0.7–1**: natural writing, brainstorming<br>• **above ~1.3**: increasingly random; can drift into nonsense<br><br>**Tips:**<br>• Change **either** `temperature` **or** `top_p`, not both (both control randomness).<br>• Some models (e.g. reasoning models) don't support it; check the model's page. |
| **logprobs** | **What it is:** short for **log probabilities**. With `logprobs` turned on, the API returns, for each token in the answer, **how probable the model thought that token was**.<br><br>**Why "log":** the value is the natural logarithm of the probability. Probabilities of long texts are multiplied together and quickly become tiny numbers; logs turn that multiplication into simple addition and avoid numbers too small for a computer to store.<br><br>**Reading the values:** always **0 or negative**. Closer to 0 = more confident.<br>• 0 → 100%<br>• −0.1 → about 90%<br>• −0.69 → 50%<br>• −2.3 → 10%<br>• −4.6 → 1%<br>Convert back with: probability = e^logprob (Python: `math.exp(logprob)`).<br><br>**Parameters (OpenAI):**<br>• `logprobs: true` → return the logprob of each output token<br>• `top_logprobs: n` (0–20) → also return the **n most likely alternatives** at each position<br><br>**Uses:**<br>• A **confidence score**, e.g. for a yes/no or category answer<br>• Spotting **uncertain parts** of an answer (low logprobs can signal guessing)<br>• Showing **alternative words**, e.g. for autocomplete<br><br>**Notes:**<br>• It describes the model's *confidence*, not whether the answer is *true*: a model can be confidently wrong.<br>• Not available for every model or API; check the model's page.<br>• In LangChain: `ChatOpenAI(model=..., logprobs=True)`; the values appear in the response's `response_metadata["logprobs"]`. |
