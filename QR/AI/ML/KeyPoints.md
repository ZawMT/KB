| Key Point | Note |
|-----------|------|
| DL | DL (Deep Learning) is a subset of machine learning that uses neural networks with many layers ("deep" networks) to automatically learn complex patterns from large amounts of data. It powers things like image recognition, speech processing, and LLMs, and excels at tasks where features are too complex to define manually. |
| LLM | An LLM (Large Language Model) is a subset of DL. It is a type of AI model trained on massive amounts of text data to understand and generate human-like language by predicting the next word in a sequence. Examples include Claude, GPT, and Gemini, which power applications like chatbots, writing assistants, and code generation. LLMs were trained purely on text data, which is where the name comes from. But modern LLMs have largely evolved into multimodal models that can also process images, audio, and sometimes video, even though "language model" remains the common label. |
