| Key Point | Note |
|-----------|------|
| DL | DL (Deep Learning) is a subset of ML that uses neural networks with many layers ("deep" networks) to automatically learn complex patterns from large amounts of data. It powers things like image recognition, speech processing, and LLMs, and excels at tasks where features are too complex to define manually. DL uses neural networks with many layers (e.g., CNNs, RNNs, Transformers). |
| Emergent capabilities | Emergent abilities (the term as popularized by Wei et al., 2022, "Emergent Abilities of Large Language Models") refer to capabilities that appear as a function of scale — model size, parameters, or training compute. A small model can't do the task at all, and then past some scale threshold a larger model suddenly can. The jump is along the size axis. |
| Grokking | Grokking is a surprising phenomenon where a model suddenly generalizes long after it has already memorized the training data. Grokking is a jump along the training-time axis. Nothing about scale is changing. |
| LLM | An LLM (Large Language Model) is a subset of DL. It is a type of AI model trained on massive amounts of text data to understand and generate human-like language by predicting the next word in a sequence. Examples include Claude, GPT, and Gemini, which power applications like chatbots, writing assistants, and code generation. LLMs were trained purely on text data, which is where the name comes from. But modern LLMs have largely evolved into multimodal models that can also process images, audio, and sometimes video, even though "language model" remains the common label. |
